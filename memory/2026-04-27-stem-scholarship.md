All of the OpenClaw config files are ordinary JSON/YAML files, so a standard `jq` command does the job.

---

### 1️⃣ Basic pattern – replace the primary model

```bash
# <file> is the JSON file that contains the snippet you posted
# (e.g. /root/.openclaw/workspace/volt/config.json or whatever you created)

jq '.model.primary = "openrouter/openai/gpt-4:free"' \
    /path/to/your/file.json > /tmp/tmp.json && \
mv /tmp/tmp.json /path/to/your/file.json
```

*What it does*  
1. Loads the JSON file.  
2. Sets `model.primary` to the new string you provide.  
3. Writes the modified JSON to a temporary file (`/tmp/tmp.json`).  
4. Atomically replaces the original file with the temporary one (so you don’t end up with a half‑written file if the command is interrupted).

---

### 2️⃣ Add a fallback model (append to the `fallbacks` array)

```bash

    /path/to/your/file.json > /tmp/tmp.json && \
mv /tmp/tmp.json /path/to/your/file.json
```

*Result* – the `fallbacks` array will now contain the new entry, preserving any that were already there.

---

### 3️⃣ Remove all fallbacks (empty the array)

```bash

    /path/to/your/file.json > /tmp/tmp.json && \
```
