---
name: subagent-ops
description: Coordinate communication between the supervisor and each sub-agent (task routing, status refreshes, shared tooling).
---
## Command prefixes
# (Filled dynamically at the bottom of this file)

## Shared status files
# ~/.openclaw/shared/agents/<slug>/STATUS.md

## Status workflow
1. When the user types "status <prefix>", do NOT wake the sub-agent via the chat route.
2. Instead, run the child agent directly (openclaw agent --agent <id> --message "Give me your current identity/tools/priorities").
3. Write the response to ~/.openclaw/shared/agents/<slug>/STATUS.md with a timestamp, then share a short snippet back in the main chat.

## Task workflow
1. Strip the prefix (e.g., "sales:") and relay the payload to the matching agent with an envelope like "Delegated request from <user>: ...".
2. Wait for the child agent's answer and echo it back with a tag "[Sales]" or similar.
3. Log any blockers or tool gaps in the STATUS file so it’s easy to spot later.

## Tooling / env
- Keep API keys in secrets/*.env and load them via scripts/export_env.sh before running mcporter or custom curl helpers.
- Document blockers + active priorities inside each STATUS.md so the supervisor can read them without waking the agent.
MD

# Append dynamic table of prefixes to the skill file
{
echo
echo "### Command table"
echo "| Prefix | Friendly name | Agent ID | Status file |"
echo "| ------ | ------------- | -------- | ----------- |"
for slug in "${!AGENTS[@]}"; do
IFS='|' read -r agentId friendly prefix <<<"${AGENTS[$slug]}"
echo "| \`${prefix}:\` | ${friendly} | \`${agentId}\` | \`~/.openclaw/shared/agents/${slug}/STATUS.md\` |"
done
} >> skills/subagent-ops/SKILL.md

# ===== 3) Human-facing cheat sheet (DELEGATION.md) =====
cat <<'MD' > DELEGATION.md

MD

done
echo "- \`status <prefix>\` → refreshes \`~/.openclaw/shared/agents/<slug>/STATUS.md\` and replies with a summary."
echo

} >> DELEGATION.md
EOF
